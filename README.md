# Сайт ООО «СитиСтрой» (Казань)

Сайт строительной компании: гражданское и промышленное строительство, генеральный подряд,
поставки цемента. Без внешних библиотек и сборщиков — чистые HTML, CSS и JavaScript.

## Что где лежит

| Папка | Что это |
|---|---|
| `site/` | **Готовый сайт.** Именно эту папку заливают на хостинг |
| `site/mail/` | Приём заявок с формы (PHP + PHPMailer) |
| `_build/` | Исходники, из которых собираются страницы |

## Как вносить правки

Страницы в `site/` собираются автоматически — **править их напрямую нельзя**, изменения
затрутся при следующей сборке. Редактировать нужно исходники в `_build/`:

* `_build/shell.html` — общий каркас: шапка, мобильное меню, футер;
* `_build/pages/*.html` — содержимое конкретных страниц;
* `_build/parts/*.html` — повторяющиеся блоки (форма заявки, карточки объектов, галереи).

После правок запустить сборку — она пересоберёт все 15 страниц:

```
powershell -File _build/build.ps1
```

Стили (`site/assets/css/style.css`) и скрипты (`site/assets/js/main.js`) правятся напрямую.

## Заявки с сайта

Форма отправляет письмо через `site/mail/send.php`. Все настройки — в одном файле
`site/mail/config.php`: адрес получателя (`TO_EMAIL`) и данные почтового ящика-отправителя
(SMTP). В файле есть подробная инструкция.

> **Важно:** репозиторий публичный. Не сохраняйте здесь реальный пароль от почты —
> вписывайте его в `config.php` уже на хостинге. Если пароль всё же нужно хранить в
> репозитории, сделайте репозиторий приватным в настройках GitHub.

Каждая заявка дополнительно записывается в `site/mail/log/requests.log` — на случай, если
письмо не дойдёт. Эта папка в репозиторий не выгружается.

## Требования к хостингу

PHP 7.4 или новее. Модуль `mbstring` желателен, но не обязателен. Для страницы «Контакты»
используется виджет Яндекс.Карт — ключ API не нужен.
